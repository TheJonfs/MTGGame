# Icon prompts

Icons are **single-color ink glyphs** (no wash), generated at 1024 square on transparent, then traced to SVG and normalized to a 24px grid, 2px stroke. Generate 3–4 candidates each; keep one.

Preamble: see `style.md`, then: "A single simple ink glyph, centered, bold readable silhouette, no shading, no wash, no background. Subject: …"
