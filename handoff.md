## Concerns

1. **The fount cannot be tuned by life** (the table above). The capstone is currently as hard as the phase-one Heart for a finished deck (86–89%) and unwinnable for a floor deck. Whether that is right depends on what deck arrives at the deep water after five lords — which nothing measures yet: a "post-lords" reference (a salvage deck plus ten golds and five lords' cards) would be the honest yardstick for both the fount and the courts.
2. **The turn order is explicit now.** `state.activePlayer` for turn N is no longer `(N − 1 + startingPlayer) % 2`. Nothing in the repo derived it that way (I grepped engine, agents and the match UI), and replays re-run the loop, so old logs replay; but any future code that infers whose turn it was from the turn number will be wrong the moment a Walk resolves. The viewer's turn banner reads `activePlayer` — fine.
3. **Time Walk in the AI's hands is priced, not planned**: it values the extra attack, not the extra land drop or the untap of a tapped-out board; good enough for a prize the AI will essentially never hold.
4. **"The Emberford" still collides** (a phase-one red region beside the red stronghold "Emberford"), because the names were held.
5. **`ifLawsAtLeast` reads the count at resolution only** — the printed intervening "if" is not checked at trigger time. No card in the pool can change the law count in response in a way that matters more than it already does (destroying a law in response to the trigger changes the outcome the same way under both readings, except that a true intervening-if would never have triggered at four). Registered as a simplification.
6. **Odile's matchup against a finished deck** (20%, three sessions running) is a property of the design — a court that punishes tapped creatures against a deck that kills with a few large untapped-by-vigilance or burn sources. Worth a planner look before her row is ratified with the rest.
