# Token art: elemental_5_3_g (Elemental Token — Titania's)

Card-art class (S7 feedback round / S17 Expansion 1: tokens get our own art
rather than Scryfall pulls — they are custom defs, so oracle grounding
doesn't apply). House style like the goblin/soldier tokens. Rendered 1:1,
center-cropped to the frame's 5:4 art window. S20 playtest round 1: the
5/3 Elemental Titania raises from her dead lands was the one token without
a plate.

A towering forest elemental, a gentle giant of the deep woods standing
