# Token art: elemental_1_1_r (Elemental Token — Young Pyromancer's)

Card-art class (S7 feedback round / S29–S30: tokens get our own art rather than Scryfall pulls —
they are custom defs, so oracle grounding doesn't apply). House style like the goblin/soldier
tokens. Rendered 1:1, center-cropped to the frame's 5:4 art window. S30 Part 6: the Pyromancer's
1/1 red Elemental was the one token without a plate (the green 5/3 is Titania's).

## Visual descriptor (locked)

A small darting fire elemental, a wisp of living flame no taller than a
