## Deviations from the brief

1. **The pool-registry `shopTier` column is a section, not a per-row column** — the canonical value lives on the card defs (loader-validated), the audit doc curates, `pnpm card-manifest` renders the human sheet. A 100-row hand-edit would rot; the guard can't.
2. **R sell price** (a player selling an ante-won R card) uses the T3 multiplier — the audit prices R as "—". Interim, flagged for the R-economy design.
3. **Card-courier takes spares only** (deck copies refused) — ADR-069 says "from your collection"; the stricter read keeps ADR-065's deck-integrity invariant without a refill dance. Escalate if the looser read was intended.
4. **Bounty targets never expire** (the mark keeps roaming) — the brief gave deadlines to couriers ("optional step deadline per quest"); a bounty with a deadline plus a wandering target read as feel-bad. Flag if wrong.
5. **Manalink over-cap converts to its gold value** rather than being undropped — offers are seeded before the cap check can know the future; a dead reward at turn-in felt worse than gold in lieu.
6. **`beastTierFallback` is now dead code for signature rolls** (the grid is complete) — retained as insurance per ADR-078; the OQ-4 `mage` default is formally nodded.
