# Surface: frame texture — multicolor (hammered gold)

Card-frame body texture (S7 feedback round 2: 1993–97-style textured
frames instead of flat color). Used behind the frame's parchment panels;
value range kept narrow so panels and art pop.

## Visual descriptor (locked)

```text
Burnished gold metal texture seen flat-on: warm brassy ochre with soft hammered dimples and faint tarnish mottling, like the gold frame of an old multicolor card. A seamless repeating texture swatch filling the canvas edge to edge —
no border, no outline, no objects, no vignette; the pattern runs off all
four sides. Flat even lighting, narrow value range, fine ink hatching
with watercolor wash in the house style.
```
