# Surface: frame texture — artifact (gray-brown stone)

Card-frame body texture (S7 feedback round 2: 1993–97-style textured
frames instead of flat color). Used behind the frame's parchment panels;
value range kept narrow so panels and art pop.

## Visual descriptor (locked)

```text
Warm gray-brown granite texture seen flat-on: one continuous surface of fine speckled mottling with faint tool scratches and umber flecks — a single unbroken polished stone face, no individual stones, no boulders, no seams. A seamless
repeating texture swatch filling the canvas edge to edge — no border,
no outline, no vignette; the pattern runs off all four sides. Flat even
lighting, narrow value range, fine ink hatching with watercolor wash in
the house style.
```
