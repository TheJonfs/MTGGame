## Deviations from the brief

1. **The save's deck shape is unchanged (Chris, 2026-09-15).** The brief's `world.decks: {id, name, list, notes, createdAt, updatedAt}[]` + `activeDeckId` + a "Deck 1" migration + a format bump: not done. The S16 record (name-keyed, `activeDeckName`) carries every operation the brief lists; `notes`/timestamps are not added (nothing shows them). If the planner wants notes on a deck, that is a `world-save-v8` with an optional field — cheap, but it wants a reason.
2. **The bosses join the production single-game picker**, gated by the unlock rule (a lord's deck appears once his signature has been met in a duel or is owned). The brief asked for saved decks beside the starters and roads; Chris asked for the gallery's filter on the picker — and no mage or beast deck carries a prizeOnly card, so the filter would have gated nothing. The bosses are what the rule is *for*. Starters and roads are not in the production picker (the roads are dev pilots; the starters are the world's).
3. **The spawn roll's layout.** `mageSpawnWeight` is the brief's weights, but the pick lays the tiers out by weight descending, ties by tier descending, and draws once — the one rule that reproduces all three S18 tables byte-for-byte (the pin). Any other default would have changed which roamer a seed spawns. **`mageSpawnRamp` is my reading**: the tier-2/3 weights × ramp^(stepsTaken/100) at respawn (generation is step 0). The brief's "a per-step-count multiplier" fits several curves; the exponent per hundred steps is documented in the knob and is one line to change.
4. **The door refuses the FIGHT only.** Flee and buy-off stay for a door-ruled roamer (an encounter must remain leaveable; there is no "walk away" on the parley). A failed flee against a door-ruled template loses the stake and shows the refusal (the roamer stays). Phase-two doors will be fixed sites, not roamers — Concern 2.
5. **`checkDeck` takes the pool** (the brief's signature had none): the colour, creature, land and mana-value rules read the cards. Without a pool a card-reading rule throws rather than admit; `parley` takes `{ pool }` in its opts (the controller passes it; CLIs and sims that never meet a ruled template are unaffected).

## Concerns

1. **The planner's model of the UI was a session or more stale** (several decks per save, the Lab's editor as the model for what "the editor" lacked). The reference docs cover cards, enemies and starters, not what the screens can do. A short planner-readable "what the world UI does" page (regenerated or hand-kept) would have prevented Part 1.1 as written; I have not created one (out of scope) but recommend it before the phase-two briefs, which lean on the editor.
2. **Where phase two's doors should sit.** The parley is a roamer contact; the editor is shut while parleying (`canEdit`), so a refused player must flee or buy off to go rebuild. Strongholds and courts are fixed sites that arrive through `dungeonTelegraph` / the petal telegraph — where the editor IS reachable. The check is one call (`doorCheck` + `doorRefusalText`) and belongs on the site's telegraph (Fight shut, the line shown, "edit your deck" beside it); the parley path is the brief's, wired, and right for a ruled roamer if one is ever authored. The petal courts and the lords are `CorollaDef` / `StrongholdContentDef` entries, not `OpponentTemplate`s — phase two's `deckRule` needs to live on whichever def the new sites use (or those defs need a template id).
3. **The editor's door picker lists every ruled template.** With ten phase-two doors that is a ten-entry select; better: the door the player stands at is pre-selected (the telegraph opens the editor with `setEditorRule(id)`), and the picker stays for planning ahead.
4. **The unlock rule is card-grained.** A boss's deck unlocks when its signature is seen — but the Heart's sixty contains only the Manafleur as a prizeOnly card, so one Heart fight unlocks the whole Heart deck for single-game play. If that is too generous, gate the bosses on a *won* duel instead (the seen store does not know outcomes; a second store would).
5. **Pell measured at exactly the S35 baseline** (60/71/72/66/70 vs the five starters, +0 each): the list is S35's again and the sweep's seeds are fixed. That confirms the S36 read was the Glaciers and not noise, and leaves Pell where the tuning arc left him.
6. **The Angel's amended gate has no ladder delta by construction** — the ladder decks carry no Angel; both gates ran green (the smoke and `pnpm ladder --games 100`, mirror gate PASS). Corvane's Angel with an Unearth-only hand now holds instead of cycling; unmeasured in the sweep (Corvane is not in part 5's touched set this session).
7. **Mobile.** The editor is keyboard-free but not responsive (no media queries, a fixed two-column grid); at 800px the header wraps to three rows. Not regressed, not improved (Chris's call).

## The salvage start (§6): what it would need on top of this

- **A `newWorld` entry that takes a prescribed start instead of a catalog starter**: today `newWorld({ starter: StarterId })` seats the starter's decklist as the collection and the deck. The salvage is `{ collection, decks, gold, manalinks, legends }` — a `SalvageSpec` built by the world from the legacy blob (the ten legends' ids are already in the legacy's flags; the purse is a knob) plus the chosen shape: (1) a flowing-pair starter = five new `StarterTemplate`s keyed by pair (the catalog's starter validation generalises: `StarterId` becomes a string union); (2) a sealed pool = a `salvagePool` per pair (ids + a seeded draw count through the world RNG) and **a pick screen** — the editor's spares grid with a pick budget, a new screen kind (`salvage`) on the controller, keyboard-free; (3) both. The editor is reachable from the map already, so "the deckbuilder's first real use before the first duel" is the existing editor opened from the flood scene.
- **The flood scene**: the phase-one save's last deck as "what was lost" — the legacy blob does not carry the deck today (flags, legends, manalink terms); add `lastDeck: Decklist` at the fifth cutting's write, and one or two salvage picks from it are a `chooseFrom(lastDeck, n)` on the same pick screen.
- **The door rule on the new sites** (Concern 2) and the resolver's phase-two bundle (§8) are independent of the salvage and can precede it.
- **Single-game and the Lab read saved decks already**, so a salvage deck is measurable the moment it exists.
